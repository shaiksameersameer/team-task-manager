TEAM TASK MANAGER

Project Description:
Team Task Manager is a complete stack web app built using the MERN stack. This application allows users to sign up, log in using JWT authentication, create tasks, and get dashboard statistics.

Features:

* Sign up/Login functionality
* JWT Authentication
* Protected Routes
* Dashboard with Task statistics
* Create and Manage tasks
* MongoDB Database Integration
* Responsive Design
* Full stack deployment

Technologies Used:
Frontend Technologies:

* React.js
* React router
* Axios
* CSS

Backend Technologies:

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT
* bcryptjs

How to Run:
Step1:
git clone https://github.com/shaiksameersameer/team-task-manager.git

Step2:
cd client
npm install

Step3:
cd ..../server
npm install

Step4:
Create .env file inside server folder. 
Add:
MONGO_URI:your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000

Step5:
Run backend
npm run dev

Step6:
Run frontend
cd..../client
npm run dev

Project completed successfully
